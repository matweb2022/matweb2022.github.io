Class RoboguideAPIPlugin

This abstract class is an implementation of IRoboguideAPIPlugin that is automatically configured to listen to most events. It can be used to quickly develop a plugin by overriding a few select event callbacks.

Inheritance

RoboguideAPIPlugin
Namespace: RoboguideAPI
