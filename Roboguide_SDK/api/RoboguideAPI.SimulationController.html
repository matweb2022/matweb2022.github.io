Class SimulationController

The SimulationController controls and configures the ROBOGUIDE simulation.

Inheritance
System.Object
SimulationController
Implements

AreGraphicsUpdatesEnabled

Gets/Sets whether graphics visualization in ROBOGUIDE window will be updated during simulation.

Declaration
public bool AreGraphicsUpdatesEnabled { get; set; }
Property Value
Type Description
System.Boolean

True if the visualization will be updated during simulation, otherwise false.
Remarks

When enabled, the simulation may be dramatically slowed compared to real-time. Disable graphics updates to run the simulation at the fastest possible rate (possibly faster than real-time).

RefreshRate_Hz

Gets/Sets the number of simulation updates per simulated second

Declaration
public int RefreshRate_Hz { get; set; }
Property Value
Type Description
System.Int32

The number of simulation updates per second
Remarks

This parameter controls the period of time each object should simulate at each step of the simulation. For example, if this parameter is set to 50 updates per second, each simulated object would advance forward in time 20ms for each simulation step. This means the lower the value, the faster the simulation can run, but the less opportunity you will have to capture data and keep things in sync.

For simulations that are intended to perform collision checking, this parameter should be set to 125Hz (max value) to decrease the chances that a collision event will be missed.
