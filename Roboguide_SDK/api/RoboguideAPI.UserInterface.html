Class UserInterface

Provides methods to customize the ROBOGUIDE user interface

AreErrorDialogsSuppressed

Gets/Sets whether ROBOGUIDE error dialogs will be suppressed.

Declaration
public bool AreErrorDialogsSuppressed { get; set; }
Property Value
Type Description
System.Boolean

True if blocking error dialogs should NOT be shown, otherwise false.
Remarks

Historically, ROBOGUIDE was developed to be operated with a human in the loop for all operations. Errors that occur in routines for loading a workcell or modifying configuration settings often alert users through a blocking MessageBox. In order to allow headless operation of the software, this setting can be used to suppress many error dialogs.

Warning

Not all error dialogs are affected by this setting.
