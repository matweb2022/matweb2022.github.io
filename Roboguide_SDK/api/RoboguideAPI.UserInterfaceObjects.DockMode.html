Enum DockMode

Describes the type of docking for a dockable window

Namespace: RoboguideAPI.UserInterfaceObjects
Syntax
public enum DockMode

Fields

Name Description
Bottom

Window will dock on the bottom side of the ROBOGUIDE window.
Fill

Window will fill the remaining center area of the ROBOGUIDE window.
Left

Window will dock on the left side of the ROBOGUIDE window.
None

No docking. Window will float in the ROBOGUIDE MDI host.
Right

Window will dock on the right side of the ROBOGUIDE window.
Standalone

Window will be a standalone window with no tie to the ROBOGUIDE window.
Top

Window will dock on the top side of the ROBOGUIDE window.
