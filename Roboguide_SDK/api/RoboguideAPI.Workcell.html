Class Workcell

A workcell is a collection of IRoboguideObject and manages their creation and destruction.

Inheritance
System.Object
Workcell
Implements
IRoboguideObject
Namespace: RoboguideAPI
Syntax
public class Workcell : IRoboguideObject
Remarks

A workcell consists of robots, tooling, fixtures, parts, obstacles, etc. The workcell can create, destroy, and maintain these objects. The workcell also emits events to listeners that want to know when certain things happen. The workcell also has a SimulationController which can be used to start, stop, or reset the simulation. It also has a CollisionChecker which can report collision information for the current state of the workcell objects.

GetObjects()

Enumerates all objects in the workcell

Declaration
public IEnumerable<IWorkcellObject> GetObjects()
Returns
Type Description
System.Collections.Generic.IEnumerable<IWorkcellObject>

An IEnumerable of all objects in the workcell
Remarks

This method enumerates all known objects in the workcell.

Warning

When iterating over the workcell objects, be careful not to modify the collection. For example, do not DestroyObject inside of a foreach(var obj in Workcell.GetObjects()) as this will change the contents of the workcell object collection. The correct approach is to find the object to destroy, hold onto the reference outside the loop, then call DestroyObject.

Examples
// Print out the name of every object in the cell
foreach(var apiObject in Workcell.GetObjects())
{
    Debug.WriteLine(apiObject.Name);
}

// Find the first object with the name "MyObstacle"
IRoboguideObject myObstacle = 
    Workcell.GetObjects().FirstOrDefault(obj => obj.Name == "MyObstacle");

// Find all objects that have a name that starts with "My"
IRoboguideObject[] myObjects = 
    Workcell.GetObjects().Where(obj => obj.Name.StartsWith("My")).ToArray();


// Find all objects that have a name that starts with "My" and destroy them
IRoboguideObject[] myObjects = 
    Workcell.GetObjects().Where(obj => obj.Name.StartsWith("My")).ToArray();
