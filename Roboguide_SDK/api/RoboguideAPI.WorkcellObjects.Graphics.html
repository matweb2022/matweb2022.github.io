Class Graphics

Data that describes the graphical properties of an workcell object.

Inheritance
System.Object
Graphics
Namespace: RoboguideAPI.WorkcellObjects
Syntax
public class Graphics
Remarks

Describes some of the graphical properties of an object in the workcell. These properties impact the visualization and collision detection features of ROBOGUIDE.
