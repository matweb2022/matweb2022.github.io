Class Machine

Machines are generic workcell objects which may be composed of one or more MachineLinks, AttachedParts, and/or attached RobotGroup.

Inheritance
System.Object
Machine
Implements
IWorkcellObject
IRoboguideObject
Namespace: RoboguideAPI.WorkcellObjects
Syntax
public class Machine : IWorkcellObject, IRoboguideObject
Remarks

Machines are motion devices which can be controlled with a robot controller, device I/O, or through the API. Machines are typically used to implement positioners, aux axes, or end-of-arm tooling. Machines have a collection of child MachineLinks, AttachedParts, and can have one attached RobotGroup.
