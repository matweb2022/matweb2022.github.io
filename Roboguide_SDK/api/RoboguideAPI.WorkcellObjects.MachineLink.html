Class MachineLink

A machine link represents one moving component of a Machine.

Inheritance
System.Object
MachineLink
Implements
IWorkcellObject
IRoboguideObject
Namespace: RoboguideAPI.WorkcellObjects
Syntax
public class MachineLink : IWorkcellObject, IRoboguideObject
Remarks

A MachineLink is composed of a joint frame and a graphics frame. The joint frame represents the coordinate frame about which the child elements will move. The graphics frame represents the offset of the graphical representation of the link. The graphics frame is a child of the joint frame.
