Class RobotController

A RobotController controls connected RobotGroups.

Inheritance
System.Object
RobotController
Implements
IWorkcellObject
IRoboguideObject
Namespace: RoboguideAPI.WorkcellObjects
Syntax
public class RobotController : IWorkcellObject, IRoboguideObject
Remarks

A RobotController represents an instance of a Virtual Robot Controller, an out-of-process program that runs the same software as a real FANUC Robot Controller. This provides ROBOGUIDE a highly accurate simulation of robot motion and timing. RobotControllers have internal storage for programs and data. They can also control several RobotGroups at the same time and/or extended axes.
