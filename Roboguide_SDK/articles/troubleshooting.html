Troubleshooting

Plugin does not load

If the plugin does not seem to load, breakpoints are not hit, etc., it might be that the xfr config file was not copied to the correct directory. Verify that RoboguideApiUtiltityPlugin.xfr exists in C:\ProgramData\FANUC\ROBOGUIDE.

If the XFR config file exists, check that the plugin (and all of your plugin's dependencies) are being output to the correct folder. It should be in a subfolder of C:\ProgramData\FANUC\ROBOGUIDE\RoboguideAPI\Plugins\. You can configure your plugin's output directory using the project properties. See "Getting Started" section for more information.

This could happen for a few reasons:

  1. the DLLs might not be located where ROBOGUIDE expects them. Verify that the RoboguideAPI files were copied to the correct locations.
